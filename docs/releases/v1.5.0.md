# 🎸 [v1.5.0] - 겹쳐 치는 기타 여러 대도 채보, 왈츠 3/4 인식 개선

**AI Band Transcriber v1.5.0**은 기타가 여러 대인 곡에서 빠지던 음을 채보하고, 왈츠의 박자를 더 잘 읽는 업데이트입니다.

- 리드·리듬 기타를 다성 인식기(basic-pitch)로 채보합니다. 겹쳐 치는 기타, 리프, 아르페지오도 적힙니다.
- 탭에서 코드 사이의 단음이 손 위치 근처에 놓입니다.
- 느린 왈츠와 비엔나 왈츠를 3/4로 읽는 비율이 37%에서 58%로 올랐습니다.
- 모노 기타 반주의 화음 판정과, 건너뛴 파트의 예전 MIDI가 남던 문제를 고쳤습니다.

화면은 v1.4.0과 같습니다.

> 수치는 공개 데이터셋의 정답과 비교한 값입니다. 템포 기준값은 Ballroom 곡으로 정했기 때문에, 처음 보는 곡에서는 이보다 낮을 수 있습니다. 이번 버전은 아직 PC(GPU)에서 재측정하지 않았습니다.

**받는 법**: 아래 Assets의 `AI_Band_Transcriber_v1.5.0.zip`을 받아 압축을 풀고 `AI_Band_Transcriber.exe`(또는 `start.bat`)를 더블 클릭하세요. 이미 v1.3.0 이상을 설치했다면 새 폴더의 `src`만 기존 폴더에 덮어써도 됩니다. 새로 설치할 패키지는 없습니다(basic-pitch는 v1.3.0부터 설치됨).

## 🌟 바뀐 점 (What's New)

### 1. 🎸 기타 여러 대 (다성 인식)
- **문제:**
  - 음원 분리(Demucs)는 기타를 모두 한 트랙으로 내보냅니다.
  - 리드는 한 줄만 따라가는 인식기(CREPE)라, 겹친 기타 중 하나만 남았습니다.
  - 리듬은 코드 모양에 맞추는 방식이라, 스트럼 코드 말고는 리프·아르페지오·다른 기타를 놓쳤습니다.
- **수정:** 두 파트 모두 동시에 울리는 음을 모두 찾는 basic-pitch로 채보합니다. basic-pitch가 없는 환경에서는 예전 방식으로 동작합니다.
- **결과 (음 단위 F: 시작점과 음높이가 맞은 음표):**

  | 측정 | v1.4.0 | v1.5.0 |
  |---|---|---|
  | EGSet12 독주 12곡 + 두 대 6개 | 0.44 | **0.73** |
  | 그중 기타 두 대 | 0.23 | **0.67** |
  | Slakh 6곡 (분리된 기타 트랙) | 0.19 | **0.29** |
  | Slakh Track00010 (전체 실행) | 0.42 | **0.62** |

- **탭 운지:** 코드와 단음이 섞인 파트에서, 단음을 가장 낮은 프렛이 아니라 직전 운지 근처에 놓습니다. 코드 사이의 선율이 개방현으로 튀었다 돌아오지 않습니다.

### 2. 🎼 왈츠 3/4
- **문제:** 박 추적기가 120 BPM 쪽으로 끌려, 왈츠(약 87 BPM)를 1.5배나 2배로, 비엔나 왈츠(약 177 BPM)를 2/3배로 잡았습니다.
- **수정:**
  - 잡은 박이 음악의 반복 주기와 맞지 않으면, 가장 가까운 강한 주기(180 BPM 이하)로 다시 추적합니다.
  - 빠른 박에서 마디가 6박마다 반복되면 3박 계열로 봅니다. 6박의 가운데도 마디 시작처럼 강하면 그대로(비엔나 왈츠), 아니면 8분음표로 보고 절반으로(느린 왈츠) 줄입니다.
- **결과:**

  | 측정 | v1.4.0 | v1.5.0 |
  |---|---|---|
  | Ballroom 3/4 판정 | 37% | **58%** |
  | Ballroom 4/4 판정 | 98% | 98% |
  | Ballroom 박 정확도 F | 0.70 | **0.73** |
  | 느린 왈츠 템포 정답 | 6% | **47%** |
  | Slakh 박 정확도 F | 0.72 | **0.77** |
  | GuitarSet 템포 정답 | 25/40 | 25/40 |

### 3. 🔧 PC 재측정(v1.4.0)에서 나온 문제
- **모노 기타 화음 판정:** 쉬는 순간까지 평균해서, 짧게 끊어 치는 재즈 반주가 화음 23%로 판정됐습니다. 이제 소리가 나는 순간만 봅니다. GuitarSet 14곡의 리드+리듬 F가 0.36 → 0.40으로 올랐습니다(반주 10곡 0.32 → 0.37). 1번의 다성 인식이 이 분할 위에서 동작합니다.
- **예전 MIDI:** 이번 실행에서 건너뛴 파트(예: 화음이 없는 곡의 리듬 기타)는 지난 실행의 MIDI를 지웁니다. 다른 실행 결과가 이번 결과처럼 보이지 않습니다.

## ⚠️ 알려진 한계
- **기타가 여러 대여도 악보는 리드·리듬 두 줄입니다.** 모든 음이 적히지만, 기타별로 한 줄씩 나누지는 않습니다. 좌우로 나뉜 기타는 위치로, 모노 기타는 화음·단음 구간으로 나뉩니다.
- **밴드 곡의 기타 정밀도는 0.5 안팎입니다.** 분리된 기타 트랙에 남은 키보드 등 다른 악기 소리도 음표가 될 수 있습니다.
- **드럼이 없는 기타 독주**는 템포가 2배나 4/3배로 나올 수 있습니다. 기타 소리 자체가 그 주기로 더 강하게 반복돼서, 소리 시작점만으로는 가릴 수 없었습니다.
- **왈츠의 3/4 판정은 58%입니다.** 1.5배로 잡힌 곡 일부는 그대로 남습니다.
- **템포가 바뀐 곡:**
  - 일부 곡은 128 BPM 대신 64 BPM으로 읽힐 수 있습니다. Slakh 3곡이 그랬는데, 이 곡들은 정답 MIDI가 64 BPM입니다.
  - GuitarSet 재즈 솔로 1곡은 3/4로 읽힙니다.
- **180 BPM이 넘는 곡**(예: 퀵스텝)은 절반 템포로 적힙니다.
- **라이드 재현율은 0.32**입니다. 하이햇을 라이드로 잘못 적지 않는 쪽을 우선했습니다.
- 상업 음원의 가사가 들어간 악보는 개인 연습용으로만 쓰세요.

## 🚀 설치 안내 (Quick Start)

### 🎯 1. Windows 원클릭 실행
1. Assets의 `AI_Band_Transcriber_v1.5.0.zip`을 받아 압축을 풉니다. (또는 `git clone`)
2. 폴더 안의 **`AI_Band_Transcriber.exe`** (또는 **`start.bat`**)를 더블 클릭합니다.
3. 처음 한 번은 가상환경과 PyTorch(CUDA 가속)를 자동으로 설치한 뒤 프로그램이 실행됩니다. Python 3.10 또는 3.11이 필요합니다.

### 🛠️ 2. 필수 외부 유틸리티
```powershell
# 1. FFmpeg (오디오 변환, 유튜브 변환)
winget install Gyan.FFmpeg

# 2. LilyPond (PDF 악보 생성)
winget install LilyPond.LilyPond

# 3. MuseScore 4 (선택: MusicXML 악보 열람·재생)
winget install Musescore.Musescore
```
