# 🎸 [v1.5.1] - 리듬 기타 탭을 칠 수 있게: 손이 닿는 코드 모양, 32분음표 없는 스트럼

**AI Band Transcriber v1.5.1**은 v1.5.0의 리듬 기타 탭에서 사람이 칠 수 없는 곳을 고친 업데이트입니다.

- v1.5.0부터 기타를 다성 인식(basic-pitch)으로 채보합니다. 그런데 기타가 여러 대인 곡에서 서로 다른 기타의 음이 한 화음으로 묶여, 손이 닿지 않는 운지와 한 박에 8번 치는 리듬이 생겼습니다(PC 재측정).
- 이제 코드는 손이 닿는 모양으로만 적고, 한 번의 스트럼은 한 화음으로, 리듬 기타는 16분음표까지만 적습니다.

화면은 v1.5.0과 같고, 채보된 MIDI도 같습니다. 바뀌는 것은 악보(MusicXML/PDF)뿐입니다.

**받는 법**: 아래 Assets의 `AI_Band_Transcriber_v1.5.1.zip`을 받아 압축을 풀고 `AI_Band_Transcriber.exe`(또는 `start.bat`)를 더블 클릭하세요. 이미 v1.3.0 이상을 설치했다면 새 폴더의 `src`만 기존 폴더에 덮어써도 됩니다. 새로 설치할 패키지는 없습니다.

## 🌟 바뀐 점 (What's New)

### 1. ✋ 손이 닿는 코드 모양
- **문제:** `6:3 5:2 4:0 3:16 2:0 1:2`처럼 한 줄만 16프렛인 모양이 나왔습니다. 두 기타의 음이 한 화음이 된 것입니다.
- **수정:**
  - 코드의 누른 프렛(개방현 제외) 폭을 4칸 이하로 제한합니다.
  - 모든 음을 담는 모양이 없으면 가장 많은 음을 담는 모양을 고릅니다. 베이스 음을 우선으로 남기고, 나머지 음은 악보에서 뺍니다.

### 2. 🥁 스트럼은 한 화음으로
- **문제:** 한 번의 스트럼이나, 두 기타가 거의 같이 친 음이 32분음표로 쪼개졌습니다. 그래서 한 박에 8번 치는 리듬이 나왔습니다.
- **수정:**
  - 화음이 된 묶음에는 60ms 안에 늦게 친 음도 들어갑니다.
  - 빠른 단음 연주는 예전처럼 35ms 기준으로 나눕니다.
  - 화음은 32분음표로 적지 않고, 리듬 기타 파트는 16분음표보다 잘게 적지 않습니다.

## ⚠️ 알려진 한계
- **악보에서 뺀 음:** 칠 수 없어서 뺀 음은 악보에만 없고, MIDI 파일에는 남아 있습니다.
- **기타가 여러 대인 곡:** 악보는 리드·리듬 두 줄입니다.
- **기타를 거의 치지 않는 곡:** 분리된 기타 트랙에 남은 다른 악기 소리가 음표가 될 수 있습니다. 예를 들어 Slakh Track00015는 정답 50음에 393음이 나왔습니다.
- **템포:**
  - 드럼이 없는 기타 독주는 템포가 2배나 4/3배로 나올 수 있습니다.
  - 왈츠의 3/4 판정은 58%입니다.
- 그 밖의 한계는 [v1.5.0 릴리즈 노트](v1.5.0.md)와 같습니다.

## 🚀 설치 안내 (Quick Start)

### 🎯 1. Windows 원클릭 실행
1. Assets의 `AI_Band_Transcriber_v1.5.1.zip`을 받아 압축을 풉니다. (또는 `git clone`)
2. 폴더 안의 **`AI_Band_Transcriber.exe`** (또는 **`start.bat`**)를 더블 클릭합니다.
3. 처음 한 번은 가상환경과 PyTorch(CUDA 가속)를 자동으로 설치한 뒤 프로그램이 실행됩니다. Python 3.10 또는 3.11이 필요합니다.

### 🛠️ 2. 필수 외부 유틸리티
```powershell
# 1. FFmpeg (오디오 변환, 유튜브 변환)
winget install Gyan.FFmpeg

# 2. LilyPond (PDF 악보 생성)
winget install LilyPond.LilyPond

# 3. MuseScore 4 (선택: MusicXML 악보 열람·재생)
winget install Musescore.Musescore
```
