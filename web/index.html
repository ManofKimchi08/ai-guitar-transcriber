엔진 찾는 중…

이 PC에서 엔진을 찾고 있습니다…

내 PC의 GPU로 악보 만들기

이 페이지는 화면만 보여 주고, 변환은 사용자 PC에서 도는 엔진이 합니다. 음원은 인터넷으로 올라가지 않습니다.

  1. 엔진 받기 엔진 내려받기 (zip) Windows 10/11 · NVIDIA GPU 권장 · Python 3.10/3.11 필요
  2. 처음 한 번 설치: 압축을 풀고 start.bat을 실행합니다. 10~20분쯤 걸립니다.
  3. 엔진 켜기: run_engine.bat을 실행하면 이 페이지가 열리고 자동으로 연결됩니다.

PDF 악보에는 LilyPond가 필요합니다: winget install LilyPond.LilyPond, 유튜브 링크에는 FFmpeg가 필요합니다: winget install Gyan.FFmpeg

엔진을 켜면 몇 초 안에 자동으로 연결됩니다.

이 브라우저는 내 PC의 엔진에 접속하지 못할 수 있습니다. 크롬이나 엣지를 권장합니다.

엔진과 연결하기

엔진 창에 보이는 연결 코드 6자리를 입력하세요. 브라우저마다 처음 한 번만 하면 됩니다.

브라우저가 "이 기기의 다른 앱 및 서비스에 액세스" 권한을 물으면 허용을 누르세요.
